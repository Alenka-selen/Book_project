# Book_project
Трекер прочитанных книг
Запускать через python main.py
В главное меню выводится список из 5-ти пунктов:
1. Добавить книгу
2. Показать список книг
3. Рассчитать среднюю оценку книг
4. Вывести статистику авторов
5. Удалить книгу
Выход из программы осуществлется вводом enter.
При выборе 1-го пункта используется функция add_book(), которая принимает автора, название, оценку, дату прочтения книги и записывает словарь в файл books.json.
Во 2-ом пункте используется функция show(), которая оформляет и выводит список книг из файла books.json.
В 3-ем пункте используется функция middle_score(), которая суммирует оценки каждого элемента из файла books.json и выводит среднюю оценку.
В 4-ом пункте используется функция stats(), которая собирает словарь из автора: количество книг этого автора из списка книг в books.json, оформляет и выводит полученный словарь.
В 5-ом пункте используется функция delete(), которая принимает автора, название книги для удаления, проверчет существование данной книги в файле books.json и удаляет данную книгу из файла.
